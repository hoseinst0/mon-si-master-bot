# 🏰 ربات نقش‌آفرینی آکادمی ریون‌مور (Ravenmore Academy RPG)

ربات تلگرامی RPG بر پایه‌ی سند طراحی «قوانین آکادمی ریون‌مور»: تاس، روحیه، دانش جادویی، سکه،
درخت ۱۷ جادویی، بازار هفتگی، نامه‌های دوره‌ای، کوئست‌های اصلی/جانبی/مخفی/دوئل در ۳ فصل، و پنل ادمین.

مالک ربات و ادمین‌ها هم دقیقاً مثل بقیه کاراکتر می‌سازند و بازی می‌کنند؛ دستورات ادمین فقط
قابلیت اضافه هستند و جلوی بازی‌کردن عادی‌شان را نمی‌گیرند.

---

## ⚙️ متغیرهای محیطی لازم

| متغیر | توضیح |
|---|---|
| `BOT_TOKEN` | توکن ربات از @BotFather |
| `MONGODB_URL` | آدرس اتصال Mongo (مثلاً از MongoDB Atlas رایگان) |
| `OWNER_ID` | آیدی عددی تلگرام مالک ربات (همیشه ادمین است) |
| `HOURS_PER_ACADEMY_DAY` | اختیاری، پیش‌فرض ۴۸ (طبق سند: هر ۲ روز واقعی = ۱ روز آکادمی) |

برای گرفتن آیدی عددی خودت: ربات را بالا بیاور، `/start` بزن، بعد `/whoami` را بزن.

## 🚀 Deploy روی Railway (از موبایل)

1. یک ریپوی جدید در GitHub بساز و همه‌ی این فایل‌ها را آپلود کن.
2. برو [railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo**.
3. یک دیتابیس Mongo رایگان از [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) بساز و connection string آن را بردار.
4. در تب **Variables** پروژه‌ی Railway این‌ها را اضافه کن:
   ```
   BOT_TOKEN = توکن ربات
   MONGODB_URL = connection string مونگو
   OWNER_ID = آیدی عددی تو
   ```
5. Redeploy کن. ربات آنلاین می‌شود ✅

## 🎮 دستورات کاربران

| دستور/دکمه | توضیح |
|---|---|
| `/start` | شروع بازی + ساخت کاراکتر |
| `/menu` | باز کردن منوی اصلی |
| `📋 کارنامه` | دیدن کارنامه شخصی |
| `📜 کوئست بعدی` | نامه‌ی جدید + شروع/ادامه‌ی کوئست اصلی |
| `🗺 کوئست‌های جانبی/مخفی` | دیدن کوئست‌های مخفیِ در دسترس |
| `🧙 جادوها` | دیدن درخت ۱۷ جادو و وضعیت باز/قفل |
| `🎒 کوله‌پشتی` | دیدن آیتم‌ها |
| `🛒 بازار ریون‌مور` | خرید آیتم با سکه |
| `🛏 خوابیدن` | +۲ روحیه، جلوگیری از جریمه‌ی نخوابیدن |
| `/duel` | دوئل تمرینیِ تکرارپذیر (هر نیم ساعت یک‌بار) |

کوئست‌های مخفی با گفتن جمله‌ی خاص در مکان خاص فعال می‌شوند (مثلاً در کتابخانه: «درب پشت قفسه سوم را بررسی می‌کنم»).

## 🛠 دستورات ادمین (`/admin` برای دیدن لیست کامل)

`/give_coin` `/give_knowledge` `/give_item` `/give_spell` `/set_mood` `/reset_player`
`/players` `/broadcast` `/advance_day` `/make_admin` `/remove_admin` `/whoami`

فقط مالک ربات (`OWNER_ID`) می‌تواند ادمین اضافه/حذف کند. مالک همیشه دسترسی ادمین دارد
حتی بدون این‌که در لیست ادمین‌های دیتابیس باشد.

## 🧩 نکات طراحی

- **تقویم آکادمی**: یک تسک پس‌زمینه هر ۱۵ دقیقه چک می‌کند که آیا `HOURS_PER_ACADEMY_DAY`
  ساعت گذشته یا نه؛ اگر گذشته، یک «روز آکادمی» جلو می‌رود و برای همه پیام می‌فرستد
  (نامه در روزهای فرد، یادآوری خواب در بقیه‌ی شب‌ها).
- **کوئست بعدی شخصی‌سازی‌شده**: چون بازیکن‌ها با سرعت‌های متفاوت پیش می‌روند، نامه‌ی عمومی
  فقط اطلاع‌رسانی می‌کند؛ هرکس با زدن «📜 کوئست بعدی» دقیقاً کوئستی را می‌بیند که نوبتش رسیده.
- **قفل هم‌زمانی**: هر تغییر روی کاراکتر (خرید، پاداش کوئست، دوئل) داخل `player_lock`
  انجام می‌شود تا دو اکشن هم‌زمان دیتای هم را از بین نبرند.
- برای گسترش فصل‌های بعدی یا افزودن آیتم/جادوی جدید، کافی است `game_data.py` و
  `quests_data.py` را ویرایش کنی — بقیه‌ی موتور بازی خودکار با آن‌ها کار می‌کند.
