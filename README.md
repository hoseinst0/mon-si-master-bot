# مارکت اکانت CoD Mobile — ربات تلگرام

## نصب
```bash
pip install -r requirements.txt --break-system-packages
```
یا داخل virtualenv:
```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## تنظیمات
فایل `config.py` رو باز کن و این‌ها رو عوض کن:
- `BOT_TOKEN` — توکن ربات از BotFather
- `MONGO_URI` — آدرس اتصال MongoDB (اگه لوکاله همون پیش‌فرض کافیه)
- `ADMIN_IDS` — آیدی عددی خودت و ادمین‌های دیگه (برای پنل حل اختلاف و آنتی-اسکم)
- `PUBLIC_ESCROW_CHANNEL_ID` — اختیاری، اگه می‌خوای شمارش معکوس معاملات تو یه چنل عمومی نمایش داده بشه

MongoDB باید از قبل نصب و روشن باشه (یا از MongoDB Atlas رایگان استفاده کن).

## اجرا
```bash
python bot.py
```
با یک اجرا، هم ربات تلگرام (polling) و هم پنل وب مدیریت هم‌زمان روی یک پروسس بالا میان.

## پنل مدیریت داخل ربات
تو تلگرام به ربات دستور `/admin` رو بزن (فقط برای آیدی‌های داخل `ADMIN_IDS`). امکانات:
- 📊 آمار زنده (کاربران، آگهی‌ها، حجم معاملات، اختلافات باز)
- 👥 جستجوی کاربر با آیدی یا یوزرنیم + بن/آنبن + تغییر دستی موجودی
- 📦 آخرین آگهی‌ها + حذف آگهی
- 💬 اختلافات باز + دکمه رسیدگی مستقیم
- 💳 آخرین تراکنش‌ها
- 📢 پیام همگانی به همه کاربران فعال

## پنل وب مدیریت
یک داشبورد وب جدا (`web_panel/`) با FastAPI ساخته شده که با اجرای `bot.py` خودکار بالا میاد.

**تنظیمات لازم (در `config.py` یا Environment Variables):**
- `WEB_PANEL_USERNAME` — نام کاربری ورود (پیش‌فرض: admin)
- `WEB_PANEL_PASSWORD` — رمز عبور ورود (⚠️ حتماً قبل از پابلیک شدن عوضش کن!)
- `WEB_PANEL_SECRET_KEY` — کلید امضای سشن (⚠️ این هم حتماً عوض کن)
- `PORT` — پورتی که Railway خودش ست می‌کنه (یا `WEB_PANEL_PORT` برای اجرای لوکال)

بعد از اجرا، به آدرس `http://<host>:<port>/login` برو و با یوزر/پس واردشده لاگین کن.

صفحات پنل وب:
| مسیر | کاربرد |
|---|---|
| `/` | آمار کلی و حجم معاملات |
| `/users` | جستجو، بن/آنبن کاربران |
| `/listings` | مشاهده و حذف آگهی‌ها با فیلتر وضعیت |
| `/disputes` | رسیدگی به اختلافات با یک کلیک |
| `/transactions` | لیست کامل تراکنش‌های Escrow |

روی Railway اگه بخوای پنل وب رو از بیرون در دسترس داشته باشی، باید تو تنظیمات سرویس یه **Public Domain** براش فعال کنی (تب Settings → Networking → Generate Domain) و پورتش رو با متغیر `PORT` هماهنگ نگه داری (Railway خودش این متغیر رو ست می‌کنه).

## ساختار فایل‌ها
| فایل | وظیفه |
|---|---|
| `config.py` | تمام تنظیمات و عددهای قابل‌تغییر |
| `database.py` | لایه MongoDB — کاربران، آگهی‌ها، escrow، اختلاف‌ها، فینگرپرینت، رفرال |
| `states.py` | state های FSM برای فرم‌های چندمرحله‌ای |
| `keyboards.py` | کیبوردهای شیشه‌ای |
| `handlers_start.py` | `/start`، منوی اصلی، لینک رفرال |
| `handlers_listing.py` | ثبت آگهی + Account Health Check (امتیازدهی) + Smart Listing (فیلتر و پیشنهاد قیمت) |
| `handlers_escrow.py` | خرید، قفل پول در Vault، بیمه معامله، تأیید تحویل، باز کردن اختلاف |
| `handlers_auction.py` | مزایده روی اکانت‌های نایاب (ثبت پیشنهاد اتمیک، جلوگیری از race condition) |
| `handlers_trust.py` | لیدربورد امتیاز اعتماد |
| `handlers_vip_antiscam.py` | اشتراک VIP (کارمزد کمتر) + مسدودسازی فینگرپرینت کلاهبردارها |
| `handlers_admin.py` | تصمیم‌گیری روی اختلاف‌ها از طریق پیام‌های خودکار به ادمین |
| `handlers_admin_panel.py` | پنل مدیریت کامل داخل ربات (`/admin`) — آمار، کاربران، آگهی‌ها، برودکست |
| `web_panel/app.py` + `web_panel/templates/` + `web_panel/static/` | داشبورد وب مدیریت (FastAPI) |
| `bot.py` | اجرای اصلی ربات + پنل وب هم‌زمان + دو تسک پس‌زمینه (بستن مزایده‌های تموم‌شده و ریفاند escrow های منقضی) |

## نکات مهم قبل از پابلیک شدن
1. الان کیف پول (`balance`) فقط داخل دیتابیسه — باید یه سیستم شارژ واقعی (کارت به کارت / درگاه) بهش وصل کنی، چون فعلاً راهی برای واریز واقعی پول تعریف نشده.
2. `ban_fingerprint` فعلاً دستیه (ادمین با کامند می‌زنه). اگه بخوای خودکار بشه، باید یه لایه جمع‌آوری فینگرپرینت (device_id از وب‌اپ یا الگوی متنی آگهی) اضافه کنی.
3. AI Chat Assistant (سوالات پرتکرار) تو این نسخه نیومده — چون نیاز به API key جدا داره؛ اگه خواستی جدا برات وصلش می‌کنم.
4. قبل از پابلیک شدن حتماً یه بار دیگه امنیت callback_data ها رو چک کن (مثل چیزی که تو Astral Abyss با exploit استیک منفی داشتی) — اینجا همه‌ی مقادیر مثل amount و price سمت سرور از DB خونده میشن نه از callback، ولی بازم یه بار دیگه مرور کن.
